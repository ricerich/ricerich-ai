머신러닝이란?

학습 과정, 데이터셋 분리, 네 가지 학습 알고리즘

정의

컴퓨터가 대용량 데이터에서 패턴을 찾아 학습하고 예측하는 것.

아서 새뮤얼, 1959

명시적인 프로그래밍 없이 컴퓨터가 학습하는 능력을 갖추게 하는 연구 분야

톰 미첼, 1997

작업 T의 성능 P가 경험 E로 향상되면 학습한 것
스팸 필터 — T 분류 · P 정확도 · E 라벨링한 메일

전처리 규칙은 훈련 데이터에서만 계산해 검증·테스트에 적용합니다. 전체로 계산하면 정보가 샙니다(데이터 누수).

훈련 · 검증 · 테스트 6 : 2 : 2

훈련 60%검증 20%테스트 20%
  • 훈련 — 모델의 가중치를 실제로 갱신
  • 검증 — 학습 중 성능 확인, 하이퍼파라미터 선택
  • 테스트 — 학습이 끝난 뒤 단 한 번, 최종 성능 측정

테스트셋을 보고 모델을 고치는 순간, 그것은 더 이상 처음 보는 데이터가 아닙니다.

데이터가 적을 때 — 5-겹 교차 검증 신규
1회 2회 3회 4회 5회

초록이 검증 조각. 5회의 검증 성능을 평균 내어 추정합니다. 수천 건 이하이거나 모델을 공정하게 비교할 때 씁니다.

CrossEntropyLoss 안에 Softmax가 이미 들어 있습니다. 출력층에 또 넣으면 안 됩니다.

④ 훈련 앞으로 모든 실습에서 반복되는 다섯 줄

for epoch in range(num_epochs):     # 에포크 반복
  for x, y in train_loader:         # 배치 반복
    pred = model(x)                 # ① 순전파
    loss = criterion(pred, y)       # ② 손실 계산
    optimizer.zero_grad()           # ③ 기울기 초기화
    loss.backward()                 # ④ 역전파
    optimizer.step()                # ⑤ 가중치 갱신

zero_grad()를 빠뜨리면 이전 배치의 기울기가 계속 더해집니다. 초심자가 가장 많이 겪는 버그입니다.

  • 먼 단어도 직접 연결 → 장기 의존성 해결
  • 키울수록 성능이 좋아진다
