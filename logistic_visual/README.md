# 5장 부록 예제 · BSP 설비 계산 시각화

> AI활용 스마트물류 통합관리 플랫폼 과정 · 5. 스마트물류 시스템 및 자동화설비 이해
> 3차시 파이썬 실습 4개(`conveyor.py · picking.py · agv.py · sorter.py`)를 웹 화면으로 옮긴 예제

## 실행

`index.html` 을 더블클릭해 브라우저(크롬·엣지)로 엽니다. **설치할 것도, 인터넷도 필요 없습니다.**
Bootstrap 5.3 과 Chart.js 4 는 `vendor/` 폴더에 들어 있습니다.

## 메뉴 4개

| 메뉴 | 계산식 (파이썬 실습과 동일) | 화면 |
|---|---|---|
| ① 컨베이어 처리량 | 속도 ÷ (박스 길이 + 간격) × 60 | 벨트 애니메이션(1 m 눈금·카운트 센서) · 간격 3종 처리량 그래프 · 실습 표 |
| ② 피킹 동선 거리 | 맨해튼 거리, 통로별 지그재그 정렬 | 블록맵 위 작업자 2명 동시 비교 애니메이션 · 거리 막대 · 하루 환산 |
| ③ AGV·AMR 대수 | 사이클 = 거리×2÷속도 + 하역, 대수 = 올림(건수 ÷ (3600÷사이클) × (1+여유율)) | 필요 대수만큼 로봇 아이콘(운반/여유 색 구분) · 사이클 애니메이션 · 시간·건수·거리 그래프 |
| ④ 소터 용량 | 피크 물량 = 일 출고 × 피크 배수 ÷ 작업 시간, 부하 = 물량 ÷ 능력 | 부하 게이지 · 슬라이딩슈 소터 그림(분류/재순환) · 네 상황 막대 · 집중도별 곡선 |

기본값에서 나오는 숫자는 파이썬 실습 결과와 같습니다.
(3,600개/h · 284 m → 132 m · 100 m에서 15대 · 38% / 60% / 96% / 120%)

## 수업에서 바꿔 볼 것

- ① 간격을 0.15 m로 — 처리량은 늘지만 소터가 못 읽어 재순환이 늘 수 있다
- ② 「주문서 섞기」 — 주문 순서 거리는 매번 달라지지만 지그재그 거리는 그대로
- ③ 거리 60 m ↔ 100 m, 속도 1.5 m/s — 로봇 아이콘 수가 바로 바뀐다
- ④ 출고 작업 시간 16 → 8시간 — 같은 물량인데 게이지가 빨간색으로

## 참고

- 애니메이션은 이해를 돕는 그림입니다. 계산 결과는 위 식에서 나옵니다.
  (② 블록맵의 랙·가로 통로 배치는 맨해튼 거리를 그대로 보여 주려고 그린 가정입니다.)
- ④ 사진은 크로스벨트 방식 소터로, 실습의 슬라이딩슈와 방식은 다르지만 역할은 같습니다.
