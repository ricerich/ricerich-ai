딥러닝 학습 5단계 머신러닝도 흐름은 같다

① 데이터 준비
훈련 6검증 2테스트 2
세 묶음의 역할이 다르다훈련은 가중치 갱신, 검증은 튜닝, 테스트는 마지막에 단 한 번
② 모델 정의
데이터에 맞는 구조를 고른다표 → MLP · 이미지 → CNN · 순서 → RNN · 텍스트 → 트랜스포머
③ 컴파일
세 가지를 정한다활성화 함수 · 손실 함수 · 옵티마이저
회귀 MSE / 이진 BCE / 다중 Cross Entropy
④ 훈련
배치마다 가중치를 고친다순전파 → 손실 → 역전파 → 갱신
1,000개 ÷ 배치 20 = 에포크당 50회
⑤ 평가
훈련과 검증을 함께 본다훈련 ↑ 검증 ↓ 이면 과적합
정확도 하나만 보지 않는다
↺ 성능이 부족하면 ②~④로 되돌아가 다시 돈다

배치는 한 번에 처리할 양, 에포크는 전체 데이터를 반복하는 횟수입니다. 모델이 찾는 값이 파라미터, 사람이 정해 주는 값이 하이퍼파라미터입니다.
